# Исходное покрытие и локальные проверки

Для КТ-2 измерения повторены 24 ноября 2026 года на Windows x64. Приложение собрано для amd64 с Go 1.26.11. Для клиентских тестов использован Node.js 24.18.0. За отчёт отвечает Алина Лисянская. [Версия и результаты CI](../../README.md#контрольные-точки)

| Область измерения | Результат | Как получен |
| --- | --- | --- |
| Собственный Go-код во всех пакетах модуля | 65,2% операторов по `go tool cover -func` | Тесты всех пакетов с `-coverpkg=./...`, единый профиль Go. В учёт входят сервер, хранилище, команды, адаптеры и пакет веб-ресурсов |
| Правила баллов в `internal/grading` | 87,5% операторов, 21 из 24 | Подмножество того же профиля. Проверки прав и переходы между статусами выполняются в `internal/server` и входят в общий замер |
| Клиентский модуль проверки логина | 4 теста прошли, покрытие строк модуля 100% | Изолированный прогон Node.js с включённым покрытием только `src/features/auth/loginRules.ts`. Общее покрытие страниц React ещё предстоит измерить |

Go считает исполненные операторы, Node.js измеряет строки указанного файла. Измерение общего покрытия строк всего приложения и всех бизнес-правил запланировано для следующего этапа.

## Команды

Из корня проекта после установки зависимостей выполните

```sh
npm --prefix web run build
go test -count=1 -coverpkg=./... -coverprofile=coverage.out ./...
go tool cover -func=coverage.out
go vet ./...
```

Из каталога `web` для исходного замера клиентского модуля выполните

```sh
node --experimental-test-coverage --test-coverage-include=src/features/auth/loginRules.ts --test src/auth/loginRules.test.ts
```

## Проверки технического сценария

- Тесты Go прошли на временной SQLite и синтетических файлах. Проверены подтверждение и смена пароля, предметы, повторная сдача, видимость черновика, ручная оценка и публикация дробных баллов. [Тесты аккаунта](../../internal/server/users_test.go) · [Сквозной тест Classroom](../../internal/server/flow_test.go)
- Исполняемый HTTP-пример завершился с кодом 0. Закрытый эталон вернул 403 студенту, повторная сдача вернула исходный ID с 200, балл за пределами максимума был отклонён с 400, а допустимая оценка стала доступна студенту. [Скрипт и условия](../api/README.md)
- Браузерный прогон Chrome прошёл регистрацию обеих ролей, вход и восстановление пароля, вступление в предмет после заполнения профиля, просмотр PDF, выставление 0,7 балла и отказ в чтении чужого оригинала. Проверены переключение темы и мобильная ширина экрана. [Браузерный сценарий](../../web/tests/classroom.mjs)
- В прогоне 24 ноября `TestRenderedScanToDraft` использовал Poppler для чтения страницы синтетического PDF. Адаптер отправил JPEG и передал распознанную формулу вместе с эталоном на оценивание. Два локальных ответа внешних API дали один балл из одного. Ранее тот же тест прошёл в Linux с Ghostscript. [Эксперимент](../../internal/ai/scan_test.go)
- В отдельном локальном прогоне Docker Compose проверены подтверждение почты, загрузка PDF и утверждение результата. После перезапуска контейнера сохранились сессия, байты оригинала и оценка. Сервер прошёл `go vet ./...`. [Конфигурация сервиса](../../compose.yaml) · [Порядок запуска](../../README.md#запуск-через-docker-compose)
- Gitleaks 8.24.2 проверил каталог исходников перед публикацией и сообщил о нуле находок. Для каждого запуска CI предусмотрена отдельная проверка истории Git. [Шаг поиска секретов](../../.github/workflows/check.yml)

В клиентском прогоне прошли все восемь модульных тестов. Пять браузерных проверок охватили обновление вкладок и отображение окончательной оценки. [Проверка клиента](../../web/src/lib/api.test.ts) · [Проверка вкладок](../../web/tests/polling.mjs)

Для воспроизведения эксперимента по ИИ установите Ghostscript или Poppler и выполните из корня проекта следующую команду. В выводе должна появиться строка `PASS` с именем теста.

```sh
go test -count=1 -v -run '^TestRenderedScanToDraft$' ./internal/ai
```

Качество оценки и фактическая стоимость будут измерены на наборе S2. Восстановление данных и обновление учебной ВМ проверяются в отдельных стендовых испытаниях. [Стратегия](strategy.md) · [Индекс версий](../../README.md#контрольные-точки)
