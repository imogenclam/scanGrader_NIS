# ADR-004. Одна учебная ВМ и единый образ приложения

КТ-2, редакция 1 от 22 ноября 2026 года. Сборка через Docker Compose реализована. Автоматическая доставка и проверка отката запланированы. Владелец — Алина Лисянская.

## Контекст

Проверяющему нужны одна команда запуска и среда, в которой после замены версии сохранятся аккаунты, PDF и результаты. Учебный профиль S1 предусматривает 2 vCPU и 4 ГБ RAM. Хранилище рассчитано на один экземпляр приложения. Связанные требования — NFR-003, NFR-005, NFR-006 и NFR-007.

## Рассмотренные варианты

| Вариант | Последствие для проекта |
| --- | --- |
| Копировать отдельно исполняемый файл и ресурсы на ВМ | Можно обойтись без контейнера, но соответствие версий интерфейса, сервера и системной утилиты рендеринга придётся контролировать вручную |
| Несколько реплик с оркестратором | Облегчают независимые обновления, но требуют отдельного решения для очереди и постоянно доступного общего хранилища |
| Один версионируемый образ и постоянный том | React встраивается в Go-бинарник, среда рендеринга PDF устанавливается при сборке. Compose заменяет приложение с сохранением данных |

## Решение

В образ входят React, Go и Ghostscript, а зависимости закреплены в `go.mod`, `go.sum` и `package-lock.json`. Контейнер работает от непривилегированного пользователя. Compose связывает порт с loopback-интерфейсом хоста, монтирует `classroom` как `/data` и принимает настройки через окружение. Для доступа из внешней сети владелец стенда настраивает HTTPS-прокси и Secure-cookie. Готовность проверяется запросом к `/healthz`. ## Последствия и пересмотр

План CD предусматривает доставку образа по digest, запись исходного SHA и короткую остановку единственного процесса. До обновления сохраняются прошлый digest и согласованная копия тома. При несовместимой миграции отдельный восстановленный том подключается к прежнему образу. Недопустимая длительность остановки или требование горизонтального масштабирования служат основанием пересмотреть решение. [Порядок обновления и отката](../operations/deployment.md)
