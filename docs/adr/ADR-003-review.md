# ADR-003. Очередь проверок и утверждение результата преподавателем

КТ-2, редакция 1 от 22 ноября 2026 года. Архитектура принята для каркаса. Сравнение качества внешних моделей запланировано. Владелец — Артур Галимов.

## Контекст

Сдача должна сохраняться, даже если скан нечитаем или поставщик ИИ испытывает сбой. Рекомендация содержит по одной оценке с комментарием на каждую задачу. Студент получает результат после утверждения преподавателем. Связанные требования — US-003–US-006, NFR-002, NFR-008–NFR-012.

## Рассмотренные варианты

| Вариант | Последствие для проекта |
| --- | --- |
| Распознавание и оценивание в запросе загрузки | Один HTTP-вызов возвращает результат, но время внешних API задерживает подтверждение сдачи. Обрыв связи затрудняет безопасный повтор |
| Внешний брокер с отдельными обработчиками | Подходит для нескольких потребителей. Появляется необходимость согласовать подтверждения брокера с записями в прикладной БД |
| Состояние очереди в строке сдачи и один фоновый обработчик | Загрузка завершается до вызова ИИ. Захват и состояние обработки наблюдаемы в той же БД |

## Решение

Обработчик берёт сдачи по порядку ID. На обработку одной работы отводится четыре минуты. Страницы PDF поступают в Yandex Cloud OCR. Затем сервис передаёт распознанный текст и материалы задания в API, совместимое с Chat Completions. Сервер проверяет, что для каждой задачи получен допустимый балл. Если интеграция недоступна или модель запрашивает проверку преподавателя, работа переходит в состояние `manual`. После перезапуска сервера прерванная работа также становится доступной для ручной проверки. Студент видит итог после утверждения. [Успешная проверка](../architecture/d05-review.svg) · [Обработка отказа](../architecture/d06-failure.svg)

Обработчик сохраняет текст после распознавания всех страниц. При повторной проверке этот текст можно использовать, если совпадают хеш файла и версия OCR. Когда SQLite временно отклоняет запись готового черновика, обработчик повторяет запись уже полученных баллов. ## Последствия и пересмотр

В запрос передаются страницы работы и материалы задания. Сама фотография или рукописный текст могут содержать имя автора, поэтому для эксперимента используются синтетические или обезличенные работы. Стенд допускает один повтор по инициативе преподавателя при настроенном ИИ. Для окончательного выбора модели нужен размеченный набор S2. Если качество, p95 времени или стоимость выйдут за целевые границы, потребуется пересмотр модели или схемы распознавания. [Методика и лимиты эксперимента](../quality/strategy.md)
