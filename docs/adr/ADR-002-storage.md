# ADR-002. SQLite и атомарное утверждение

Решение принято для локальной версии КТ-2 от 24 ноября 2026 года. Схему данных совместно ведут Артур Галимов и Алина Лисянская.

## Контекст

После перезапуска студент должен получить прежний результат. Если преподаватель одновременно подтвердит одну работу из двух вкладок, обе записи могли бы претендовать на роль окончательной. Для US-005 и US-006 существенны права на работу, проверяемые правила перехода и сохранность результата. [NFR-003, NFR-006 и NFR-007](../requirements/nfr.md)

## Выбор

SQLite хранит данные в файле `/data/scangrader.db` на постоянном томе. Сервис включает внешние ключи и режим WAL. На процесс приходится одно открытое соединение. Транзакция записи начинается в режиме `IMMEDIATE`. В её пределах сервис читает строку с проверкой владельца и проверяет полный набор баллов. Затем он сохраняет оценки по задачам, автора и время утверждения. Читатель видит результат после фиксации транзакции. [Схема данных](../architecture/d04-data.svg) · [Реализация записи](../../src/storage/reviews.go) · [Начальная миграция](../../src/storage/migrations/001_init.sql)

| Другой вариант | Последствия для учебного стенда |
| --- | --- |
| PostgreSQL в отдельном контейнере | Поддерживает нескольких независимых писателей и сетевые подключения. На стенде с одним экземпляром добавил бы отдельную БД со своим обновлением и настройками доступа |
| JSON-файлы для каждой работы | Для атомарного обновления нескольких записей, связей и защиты от параллельной записи пришлось бы разрабатывать собственный протокол блокировок и восстановления |

## Последствия и пересмотр

Допустимая повторная попытка получает HTTP 409 и сохраняет первый итог. Сериализация записи ограничивает пропускную способность. Поводом испытать PostgreSQL станет потребность в нескольких пишущих экземплярах или превышение порога NFR-001 из-за ожидания записи на профиле S1. Восстановление всего комплекта после потери тома требует отдельной проверки DATA-01. [Конфликт двух запросов](../architecture/d06-failure.svg) · [Порядок отката](../operations/deployment.md)
